Shadow Information Spaces

Combinatorial filters for tracking targets · J. Yu and S. M. LaValle, IEEE T-RO 28(2), 2012

Code on GitHub

A robot follows a path through a floor plan: a grid office, or one of the 14 polygonal maps of the original Java implementation (including those of the paper's Figs. 11 and 15). Whatever it cannot see right now is a shadow. As it moves, shadows appear, disappear, split and merge, and targets wander in and out of view. The robot never sees a hidden target: it only records these shadow events and the targets crossing the edge of its view. From that stream alone the combinatorial filter maintains a bipartite information state and uses max-flow to compute the tightest possible bounds on the number of targets in each shadow, while a probabilistic filter tracks a truncated joint distribution of the counts. Pick a map and a path (from the Java code, digitised from the paper, or drawn by you) and turn on ground truth to compare.

Left: shadows at t0 and appeared shadows. Right: disappeared and current shadows. An edge means targets of the left vertex may now be in the right vertex. FOV crossings are pooled into ± nodes.
